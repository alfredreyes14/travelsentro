<objective>
Polish the admin dashboard sidebar's tap targets and open/close feel (D-05) and add a consistent shadow/elevation cue to the shared `Card` primitive (D-07), entirely within the existing locked brand system (D-06) — no new colors, fonts, or component logic.

Purpose: `components/ui/sidebar.tsx`'s `SidebarProvider`/`Sheet`-backed mobile drawer is already functionally correct (D-05 confirms reuse, polish-only). Its default `SidebarTrigger` (28px) and `SidebarMenuButton` (32px) sizes are below this codebase's established 44px touch-target convention (already used for the drag-handle button in `package-list-row.tsx`). Output: `app/admin/(dashboard)/layout.tsx` with larger sidebar tap targets and a polished header; `components/ui/card.tsx` with a subtle added shadow.
</objective>
