The homepage gains a hero carousel and admin-editable content sections -- value props, a featured packages grid, customer testimonials, an embedded inquiry form, and conditional Brand Partners/Corporate Clients logo sections -- all within the existing locked brand system.

## This Plan

Build 3 presentational homepage components -- the hero carousel and the two simplest content sections (value props, featured packages grid). All 3 are pure prop-driven components with zero direct Supabase calls: 06-07 (homepage composition, wave 3) does every query and passes already-shaped, already-URL-resolved data down. This keeps these components trivially reusable/testable and decouples them from `types/database.ts`'s exact shape (only 06-07 imports `Database` types directly). This plan depends only on 06-01 (for `embla-carousel-autoplay` and the regenerated types 06-07 will later use to build the props these components accept) -- it does NOT depend on 06-02's Server Actions (this plan is entirely read/display-only) and runs in parallel with 06-02 and 06-04.

Purpose: Give 06-07's homepage composition a ready-to-import Hero Carousel, Why Choose Us, and Featured Packages Grid, each independently verifiable via `npm run build` before the final page assembly.
Output: 3 new components under `components/homepage/`, all compiling cleanly and following UI-SPEC's Section Layout & Composition and Color/Typography contracts exactly.
</objective>
