<objective>
## Phase Goal

The homepage gains a hero carousel and admin-editable content sections -- value props, a featured packages grid, customer testimonials, an embedded inquiry form, and conditional Brand Partners/Corporate Clients logo sections -- all within the existing locked brand system.

(Same phase-level goal as 06-01-PLAN.md.)

## This Plan

Build the Hero Slides tab of the new `/admin/content` page: the schema, the dual create/edit form (with its slide-type branching and package picker), and the drag-reorderable list with add/edit/delete dialogs. This is the most complex of the phase's 4 admin CRUD surfaces -- it's the only one combining slide-type branching, an image upload, a cross-entity package picker, AND drag-reorder in one tab -- so it gets its own dedicated plan, distinct from 06-06's 3 simpler CRUD surfaces. Depends on 06-02 (needs `createSlide`/`updateSlide`/`deleteSlide`/`reorderSlides`, `uploadSiteContentImage`, and `readFileAsBase64` to exist and compile). Does not depend on 06-05's sibling admin plans or on any public-facing component (06-03/06-04/06-07) -- this tab is entirely self-contained admin UI, verifiable independently via `npm run build`.

Purpose: Give Admin/Staff with `can_manage_packages` full add/edit/delete/reorder control over the hero carousel's slides via the admin panel, per D-02's explicit "fully admin-editable: add/edit/delete/reorder slides" decision -- satisfying HOME-01's "admin-editable" requirement completely.
Output: 3 new files under `components/admin/content/`, ready for 06-08 to mount inside the `/admin/content` Tabs page.
</objective>
