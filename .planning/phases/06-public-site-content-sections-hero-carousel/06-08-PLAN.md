## Phase Goal

The homepage gains a hero carousel and admin-editable content sections -- value props, a featured packages grid, customer testimonials, an embedded inquiry form, and conditional Brand Partners/Corporate Clients logo sections -- all within the existing locked brand system.

(Same phase-level goal as 06-01-PLAN.md.)

## This Plan

Assemble the final admin surface: the `/admin/content` Tabs page that mounts all 4 CRUD tabs built in 06-05 (Hero Slides) and 06-06 (Why Choose Us, Testimonials, Partners & Clients), and add the sidebar nav item that makes it reachable. This is the phase's last plan -- it depends on both 06-05 and 06-06 (needs every tab's list component to exist), runs alone in wave 4 since nothing else in this phase depends on it. Without this plan, HOME-01/02/04/05/06's "admin-editable" requirement is technically code-complete but practically unreachable -- an Admin/Staff member has no way to navigate to the CRUD surface built in the prior two plans.

Purpose: Make every one of this phase's admin-editable content types actually reachable and usable end-to-end from the sidebar, closing the loop between 06-05/06-06's components and a live admin workflow.
Output: A new `/admin/content` route and a new "Content" sidebar nav item, both permission-gated identically to the existing Packages/Users pattern.
</objective>
