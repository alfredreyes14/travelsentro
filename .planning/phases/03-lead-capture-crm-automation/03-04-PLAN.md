<objective>
## Phase Goal

**As a** TravelSentro Admin or Staff member, **I want to** have every customer inquiry automatically captured as a tracked CRM lead — with the customer instantly acknowledged and my team instantly notified — and be able to view, search, and manage those leads, **so that** no inquiry is ever lost and I can follow up efficiently.

(Same phase-level user story as 03-01/03-02/03-03-PLAN.md.)

## This Plan

Build the CRM contact list — the first screen Admin/Staff see when they want to check on leads — as a searchable, filterable `@tanstack/react-table` view (CRM-05), plus the new unconditional "Contacts" nav item. This plan depends only on 03-01's schema (not on 03-02's ingestion route or 03-03's emails), so it can run in parallel with those; it delivers real, independently-verifiable value (a Staff member can already browse and search whatever contacts exist, seeded manually via the service-role client if needed for a smoke test) even before the ingestion pipeline is live.

Purpose: Give Admin/Staff a working entry point into the CRM data 03-01 makes possible, satisfying CRM-05's search/filter requirement and the phase's universal-read design (CRM-03).
Output: `/admin/crm` — a live, searchable, filterable contact list reachable from a new sidebar nav item.
</objective>
